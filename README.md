- **[E.V. (Local AI Assistant)](https://github.com/DavidCerdeiro/EV)**: An open-source, locally hosted AI assistant utilizing React + Vite for a responsive UI and FastAPI (`main.py`) for the backend. Integrated LangChain, OpenAI/ChatGroq APIs, and PostgreSQL with pgvector for efficient data handling, all containerized with Docker Compose.
